# Hub: контекст проєкту

Остання редакція: 06.10.2026. Для кожного, хто починає працювати з кодом: прочитати до першої зміни.

## Що це

Hub — власна платформа керування платним Telegram-клубом Марії Кравчук. Замінює ZenEdu (SaaS для продажу підписок через Telegram-бот). Власник проєкту і замовник — Олександр Бенедичук (`benedichuk@icloud.com`), власник акаунтів GitHub, Vercel, Neon, WayForPay. Команда маркетингу тестує і пропонує правки; один колега паралельно дописує код.

Продакшен: `https://hub-two-ivory.vercel.app` (Vercel Pro, Neon Postgres). Репозиторій `benedychuk/hub`, гілка `main` деплоїться автоматично.

## Навіщо переїзд із ZenEdu

1. Автоматичне керування доступом у закритий канал (посилання після оплати, виключення після закінчення) — головна цінність ZenEdu, яку треба відтворити.
2. Мультибот: бот «Щиро» (окремий продукт, Python, своя база) має перевіряти право доступу в Hub, а оффери продаватись у зв'язках «клуб», «бот», «клуб + бот».
3. Аналітика, якої в ZenEdu немає: переходи з пробного періоду на повний, фільтри за офферами, звіти.
4. Власні оплати через WayForPay без посередника.

## Зовнішні системи

| Система | Роль | Як підключено |
|---|---|---|
| ZenEdu | Поки що веде підписки й списання нинішніх учасниць | Імпорт через API (`src/lib/zenedu.ts`, `sync.ts`), токен `ZENEDU_API_TOKEN`; вебхук ZenEdu ще не підключено |
| Telegram | Hub-бот (новий, окремий від бота ZenEdu) | grammY, вебхук `/api/telegram/hub`, токен `TELEGRAM_BOT_TOKEN` |
| WayForPay | Оплати й автосписання | Той самий мерчант, що в ZenEdu; `WFP_MERCHANT`, `WFP_SECRET`, `WFP_REGULAR_PASSWORD`; тестовий мерчант для режиму «тестовий» |
| Бот «Щиро» | Клієнтський бот зі своєю базою; Hub керує списком доступу | `src/lib/shchyro.ts`, `SHCHYRO_API_URL`, `SHCHYRO_API_SECRET`; push-модель, див. `docs/integrations/shchyro` |
| Платформа онбордингу | Кабінет кандидатки на `mariia-kravchuk.com.ua/app` | `src/lib/onboarding.ts`, API `/api/v1/onboarding/*`, `ONBOARDING_URL`; див. `docs/integrations/onboarding` |
| Vercel cron | Тік щохвилини й щоденний запуск | `/api/cron/tick`, `/api/cron/daily` (04:00 UTC) |

## Де що лежить

- Код: `src/app` (сторінки й API), `src/lib` (логіка), `src/components` (UI), `src/db/schema.ts` (схема), `drizzle/` (міграції, генеруються `npx drizzle-kit generate`, застосовуються при збірці).
- Документи: `docs/` у цьому репозиторії. Історичні аналізи ZenEdu лежать у репозиторії `mkravchuk.com`, тека `docs/community-platform/` (01–09), вони довідкові.
- Дизайн-система: `docs/DESIGN.md`, обов'язкова для всіх екранів.
- Правила безпеки: `docs/GUARDRAILS.md`.
- Що зроблено й що далі: `docs/ROADMAP.md`, журнал `docs/LOG.md`.
- План переїзду з ZenEdu: `docs/MIGRATION-PLAN.md`.

## Як ведеться робота

Код пишуть через Claude Code (власник і колега, кожен зі свого акаунта, спільне лише в Git). Перед початком сесії Claude читає `CLAUDE.md`, звідти ці документи.
