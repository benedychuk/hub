# Асистентка Олеся: як вона живе в Hub (план)

**Статус:** затверджено; етап 1 реалізовано 2026-11-19 (`src/lib/assistant`, `/assistant`, `/api/cron/assistant`). Журнал дій — події `assistant.action` / `assistant.handoff` і відповіді `bot.reply` з source `assistant`; таблиці `assistant_threads`, `assistant_tickets`. Інструкція поведінки — `INSTRUCTION.md`.

## Як працює

1. **Звідки повідомлення.** Людина пише в Hub-бот. Асистентка відповідає лише на повідомлення, які зараз отримують заглушку «Дякую! Повідомлення отримано…». Команди бота, кнопки, відповіді на питання воронок і ключові слова воронок працюють як раніше.
2. **Буфер.** Люди часто пишуть кількома повідомленнями поспіль. Hub збирає їх і відповідає один раз, через ~20 с після останнього повідомлення. Обробка йде щохвилинним тіком, тому відповідь приходить за 20–80 с.
3. **ШІ.** OpenRouter, модель Gemini Flash, як у бота коментарів. Ключ `OPENROUTER_API_KEY` додається у Vercel як змінна оточення, у коді його немає. Модель задається в налаштуваннях асистентки.
4. **Інструменти.** Модель бачить картку людини й викликає інструменти. Інструменти — це ті самі функції Hub, що й кнопки панелі. Ліміти й правила `[Hub]` перевіряються в коді інструмента, а не моделлю.

| Інструмент | Що робить | Функція Hub |
|---|---|---|
| `card` | картка людини: підписки Hub/ZenEdu, оплати, повернення, доступи, конфлікти, «Щиро», кабінет, етери, історія звернень | `clubAccess`, `zenHubConflicts`, `shchyroEntitledFor` тощо |
| `send_channel_link` | нове посилання в канал, знімає старе блокування | `inviteNow` |
| `send_cabinet_link` | одноразове посилання в кабінет | `magicLinkFor` |
| `send_shchyro_link` | кнопка на «Щиро» | — |
| `send_offer_link` | посилання на оформлення оффера | `payLink` / оффер у боті |
| `cancel_renewal` | скасувати автопродовження Hub | `cancelAtEnd` |
| `pause` | пауза Hub (доступ закривається, списання зупиняються) | `pauseSub` |
| `extend` | подовжити підписку Hub на N днів (компенсація) | як у компенсації |
| `refund_last` | повернути останній платіж Hub і закрити доступ | `refundAttempt(…, revoke = true)` + скасування |
| `handoff` | звернення команді (звичайне / термінове / мовчки) | нове |
| `reply` | відповідь людині (текст + кнопки) | `sendToPerson` |

5. **Перевірка тексту.** Як у бота коментарів, другий прохід моделі прибирає заборонені слова, лапки й довге тире. Перевіряти можна дешевшим способом, звичайною програмою, без другого запиту до ШІ.

## Розділ меню «Асистент» (Продукти чи Система)

- **Звернення команді** — черга з позначками терміново / звичайне / мовчки. У кожному:
  - що просила людина;
  - що асистентка вже зробила;
  - кнопки «Виконати як запропоновано», «Відхилити» і «Відповісти асистентці» (інструкція, що робити далі).
- **Дії** — журнал: кому, що, коли, сума, підстава. Повернення, скасування, паузи, компенсації, видані посилання. Фільтр за типом і людиною.
- **Розмови** — останні діалоги з відповідями асистентки. Посилання в картку людини.
- **Налаштування:**
  - вимикач асистентки й окремо вимикач автоматичних дій, обидва за замовчуванням вимкнені;
  - модель;
  - ліміти;
  - тексти-винятки (ZenEdu, технічний відділ, криза).
- **Витрати** — кількість запитів до ШІ й токени за день і місяць.
- **У картці людини** — дії й звернення асистентки в історії.

## Дані (нові таблиці, міграція)

- `assistant_messages` — вхідні й вихідні повідомлення діалогу: буфер і контекст.
- `assistant_actions` — журнал дій: тип, людина, підписка чи платіж, сума, результат, підстава.
- `assistant_tickets` — звернення команді: статус, пріоритет, текст, рішення команди.
- Налаштування — у `settings` (`assistant.*`).

## Порядок запуску

1. **Етап 1.** Інструкція затверджена → база, розділ «Асистент», картка й відповіді без дій, що змінюють гроші чи доступ. Посилання (канал, кабінет, «Щиро», оффер) і звернення команді працюють.
2. **Етап 2.** Скасування, пауза, компенсація, повернення — за окремим вимикачем.
3. **Тести.** Перед увімкненням — набір сценаріїв з інтерв'ю на тестовій базі з імітацією Telegram і ШІ. Потім власник пише боту сам з тестового акаунта.
