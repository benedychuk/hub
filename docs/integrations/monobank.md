# monobank: другий платіжний шлюз Hub

**Статус:** реалізовано 2026-11-26, за замовчуванням вимкнено (шлюз для нових оплат — WayForPay).
Документація банку: https://api.monobank.ua/docs/acquiring.html (API v2410), база знань https://monobank.ua/knowledge-base/acquiring

## Що вміє

- **Перша оплата оффера** — рахунок monobank (`/api/merchant/invoice/create`), людина платить на сторінці monobank (картка, Apple Pay, Google Pay). Для підписок картка зберігається (`saveCardData`, `walletId = hub-<id людини>`).
- **Автосписання** — за збереженою карткою (`/api/merchant/wallet/payment`, `initiationKind = merchant`) тим самим розкладом, що й WayForPay (10:00 за Києвом, повтори 1/3/5 днів).
- **Вебхук** `/api/payments/monobank` — підпис ECDSA (`X-Sign`) перевіряється відкритим ключем банку (`/api/merchant/pubkey`, кешується); застарілі повідомлення (менший `modifiedDate`) ігноруються. Токен картки, що прийшов після оплати, прив'язується до підписки.
- **Повернення** — `/api/merchant/invoice/cancel` (з Hub: «Платежі → Оплати через Hub», асистентка, повернення з кабінету monobank теж закриває доступ).
- Прив'язка картки й «переїзд» (перевірочна сума) лишаються на WayForPay.

## Налаштування

1. **Vercel → Settings → Environment Variables** (тип Secret, середовище Production), потім Redeploy:
   - `MONO_TEST_TOKEN` — тестовий токен з https://api.monobank.ua/ (гроші не списуються; будь-яка картка, що проходить перевірку Луна);
   - `MONO_TOKEN` — бойовий токен з бізнес-кабінету web.monobank.ua (термінал інтернет-еквайрингу → «Інтеграції»).
   У тестовому режимі Hub використовує **лише** `MONO_TEST_TOKEN`, бойовий токен ніколи.
2. **Hub → Налаштування → Оплати → «Шлюз для нових оплат»:**
   - «WayForPay» — як було;
   - «monobank для тестувальників» — адміністратор і тестувальники (Telegram ID у полі нижче) платять через monobank, решта — WayForPay;
   - «monobank для всіх» — усі нові оплати через monobank.
3. Автосписання (підписки) в бойовому режимі запрацюють, лише коли банк погодить заявку «Оплата по підписці» (токенізація за замовчуванням вимкнена). Без неї перша оплата пройде, але картка не збережеться — підписку доведеться оплачувати вручну.

## Поточні підписки WayForPay

Картки, збережені у WayForPay, не переносяться: такі підписки й далі списуються через WayForPay. Шлюз автосписання визначає картка (`payment_methods.provider`), а не налаштування.
