# ТЗ для платформи кабінету: записи етерів за місяць

**Для кого:** розробник/агент платформи `MK_ONBOARDING_PLATFORM` (сайт `mariia-kravchuk.com.ua/app`).
**Hub-частина готова:** запити нижче вже працюють. Це доповнення до `TZ-efir.md`.

## Мета

Учасниця, яка пропустила етер, може переглянути запис у кабінеті протягом місяця. На сторінці етерів показуються картки записів: до 4 одночасно, найновіші спершу. Через 30 днів після етеру запис зникає сам. Команда нічого не прибирає вручну: список формує Hub.

## Де показувати

**Сторінка `efir.html` — це і є розділ «Етери».** Окрему сторінку не створювати: пункт меню «Етери» вже веде на `efir.html`, а постійне посилання в каналі — теж на неї. Структура сторінки:

1. **Вгорі — найближчий етер** (як зараз): картка з назвою, датою й часом, відліком і кнопкою «Дивитись етер». Якщо найближчого етеру немає — короткий рядок «Наступний етер ми анонсуємо в каналі».
2. **Нижче — блок «Записи етерів»:** сітка карток (на телефоні — одна колонка, на ширшому екрані — дві).

## API Hub

### `GET /api/v1/onboarding/streams/archive`

Заголовок `Authorization: Bearer <session_token>`.

```json
{
  "success": true,
  "logged_in": true,
  "member": true,
  "days": 30,
  "max": 4,
  "current": { "code": "GPaIC4Q", "title": "Етер 24.11", "starts_at": "2026-11-24T17:00:00.000Z", "state": "today", "has_link": true, "watch_from": "2026-11-24T16:45:00.000Z" },
  "archive": [
    { "code": "Ab12Cd3", "title": "Етер 17.11", "starts_at": "2026-11-17T17:00:00.000Z", "has_link": true, "available_until": "2026-12-17T17:00:00.000Z" }
  ]
}
```

- `current` — найближчий етер або той, що йде зараз (стани `upcoming`, `today`, `live`); `null`, якщо такого немає. Завершений етер сюди не потрапляє: він у `archive`.
- `archive` — записи етерів, що вже завершились, за останні 30 днів, найновіші спершу, не більше 4. Порожній масив — записів немає.
- `has_link` — чи є посилання на запис. Якщо `false`, кнопка неактивна з текстом «Запис з'явиться згодом».
- `available_until` — до якої дати запис буде в кабінеті.
- **Посилань YouTube у відповіді немає**, і це навмисно.

### Перегляд запису: `POST /api/v1/onboarding/streams/watch` з `{ "code": "<code картки>" }`

Той самий запит, що для етеру наживо. Hub сам віддає посилання на запис і записує перегляд.

- **Успіх:** `{ "success": true, "url": "...", "title": "...", "recording": true }`. Відкрити `url` через `window.location.href = url`.
- **Помилки:**
  - `expired` (410) — запис уже прибрано (минув місяць або з'явився новіший): «Цей запис уже недоступний». Перезавантажити список.
  - `no_link_yet` (409) — «Запис з'явиться згодом».
  - `not_member` (403) — «Записи — для учасниць клубу» і кнопка «Вступити в клуб» (`config.clubUrl`).
  - `unauthorized` (401) — показати вхід через Telegram; після входу повернутись на `efir.html` (див. `TZ-efir.md`, розділ 0.1).

## Картка запису

- Назва етеру (`title`).
- Дата за київським часом, наприклад «Вівторок, 17 листопада».
- Рядок дрібним шрифтом: «Запис доступний до 17 грудня» (з `available_until`).
- Кнопка **«Дивитись запис»** (вторинна; головна кнопка на сторінці — у найближчого етеру). Під час запиту — стан «Відкриваємо…».
- Без прев'ю з YouTube (його не можна вставляти без посилання). Замість прев'ю — однакова іконка відтворення в кольорі бренду.

## Стани

| Ситуація | Що показати |
|---|---|
| Учасниця, є записи | Картки записів (до 4) |
| Учасниця, записів немає | «Записів поки немає. Після кожного етеру запис з'являється тут на місяць.» |
| Не учасниця (`member: false`) | Блок записів не показувати; один рядок «Етери й записи — для учасниць клубу» і кнопка «Вступити в клуб» |
| Не увійшла | Кнопка «Увійти через Telegram», після входу — назад на `efir.html` |

## Оновлення

- Список завантажувати при відкритті сторінки. Якщо сторінка відкрита і `current.state` — `today` або `live`, повторювати `GET streams/archive` кожні 60 с: коли етер завершиться, він сам переїде з «Найближчого» в «Записи».
- Не кешувати список довше ніж на 5 хвилин: Hub прибирає старі записи сам, і платформа має це відразу відображати.

## Не змінювати

- Банер етеру на головній кабінету (`TZ-efir.md`, розділ 2.2) лишається.
- Стан `recent` у `streams/current` для банера лишається, як був.
- Вхід, профіль, решта сторінок без змін.

## Перевірка перед релізом

1. **Записи показуються.** У Hub є 5 етерів за останні 30 днів → у кабінеті 4 картки, найновіша перша, п'ятого немає.
2. **Перегляд записується.** «Дивитись запис» → відкривається запис. У Hub («Етери» → цей етер) людина зі статусом «запис у кабінеті».
3. **Окреме посилання на запис.** Команда вставила в Hub «Посилання на запис» → кнопка відкриває саме його, а не трансляцію.
4. **Старий запис.** Етер, якому понад 30 днів, зникає з кабінету без змін на платформі.
5. **Без посилання.** Запис без посилання → неактивна кнопка «Запис з'явиться згодом».
6. **Кандидатка без підписки** не бачить карток записів.
7. **Перехід з наживо в записи.** Через 3 год після початку етер переїжджає з «Найближчого» в «Записи».
8. **Без YouTube у коді.** У коді сторінок немає жодного посилання YouTube.
